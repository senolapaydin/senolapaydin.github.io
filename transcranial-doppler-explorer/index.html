Teaching model, not for clinical decisions. Vessel geometry is a simplified schematic; real depths vary with head size, age and anatomical variants. TCD velocities are mean flow velocities without angle correction; only the TCCS view adds an angle-corrected reading. The modelled values in variants and pathology are illustrative. The TCCS image is a schematic B-mode and colour Doppler built from the same model, not a recorded scan.

Optional background MRI (temporal view, off by default): T2-weighted ICBM 2009c nonlinear symmetric template (Fonov et al., NeuroImage 2011), an oblique slice through the midbrain tilted 10° like the mesencephalic plane, aligned to the vessel model by the midbrain and the basal cisterns. How to use

  1. Choose a window and the side on top of the device.
  2. Aim: drag in the view or use the arrow keys. The yellow mark is the sample volume.
  3. Read and save: red flows toward the probe, blue away. Save the reading under the screen.

Modes (top bar)

ExploreScan freely. Condition adds a variant or a disease and sets the probe to its main finding.
ProtocolThe standard exam, step by step, with a score.
IdentifyWhich vessel is at the gate?
CasesAn unknown patient: find the diagnosis and the side.

Grade and Test next to Condition change the severity or start a test (cuff test, recanalisation).

TCCS in the view bar switches the temporal and transforaminal windows to a duplex image (not in Identify, and in Cases only after the diagnosis). The i buttons explain each panel. For teaching only, not for clinical decisions. Show the short tour again.

Nothing to install. The tool runs in any current browser.

Open the link in Chrome. Tap ⋮ at the top right → Add to Home screen → Add.
Desktop
Open the link in Chrome, Edge, Safari or Firefox and bookmark it (Ctrl+D / ⌘D). For offline use, save the page (Ctrl+S / ⌘S) and open the file with a double-click.

The link needs an internet connection and always shows the latest version. A saved HTML file works offline but stays at its version. The home-screen icon is a shortcut to the link.
